What the search is allowed to learn
The brain has 16 rules: eight combinations of local openings in each of two memory states. Each rule chooses a movement and the next memory state. All rules start random and can mutate; no navigation algorithm is supplied.
The environment, key pickup, and door mechanics are supplied. Fitness rewards escapes, then keys collected, exploration, and shorter successful routes. The larger setting first solves 128 training mazes, then re-evaluates the population on 512. A separate set of 512 unseen mazes is used only after training.
Training mazes branch without loops. Open rooms and loops may defeat the result. A failed attempt stops after 256 actions; solving the test set is not a guarantee for every room you draw.
