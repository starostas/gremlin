# D1: isolated ELF oracle and CEGIS

The user's expanded assignment authorizes M0–M2 and D1–D6, superseding the original CPU-only stopping point in PLAN.md. Gates remain separate; hardware-dependent gates must report unavailable execution honestly.

Dependency choices: `gremlin-native` is the integration boundary for Linux x86-64 native execution. Pin `libc = 0.2.177` for Linux process/resource/seccomp/dynamic-loader interfaces and `object = 0.36.7` for read-only ELF metadata. Bubblewrap provides mount, user, PID, IPC, UTS, and network namespaces. Its actual executable hash/version, the worker executable hash, and every exposed runtime library hash enter binary identity. No target is loaded in the parent. System dependencies are explicit runtime prerequisites only for binary commands.

Sandbox: construct an empty filesystem with only the worker, target, loader, libc, libm, libgcc, and libstdc++ read-only. The C++ runtime is needed by CUDA-enabled worker executables; it is fingerprinted like every exposed library. No host home, proc, devices, writable bind mounts, or inherited environment. Drop capabilities. A worker supervisor forks before target loading; the child closes inherited descriptors, imposes address-space/CPU/core/file-size limits, and installs a default-deny x86-64 seccomp filter before dlopen (including constructors). Only loader read/memory operations and process exit remain allowed; writes, networking, process creation, exec, ptrace, and filesystem mutation terminate the child. The supervisor communicates a bounded shared-memory result after child termination; arbitrary target writes cannot emit protocol bytes. A parent wall-clock watchdog kills the entire process group. No sandbox fallback is allowed.

Supported ABI: explicitly declared ELF64 little-endian x86-64 ET_DYN and System V AMD64, 0–4 integer arguments, one integer return. An assembly call bridge sets the argument registers with signed/unsigned extension and normalizes the return pattern. Stack alignment is explicit. This ABI bridge does not infer types. Dependency resolution is restricted to the exposed runtime libraries; unsupported dependencies fail loading. Dependencies are observed under a fixed empty environment, isolated filesystem, and no-syscall function contract. Determinism is sampled by repeated inputs within a fresh worker and across fresh workers; it is evidence, not proof of purity.

Every oracle failure is a run error, including timeout, signal, missing symbol, forbidden access, inconsistent output, or incomplete worker protocol. Tests compile local fixtures only until isolation acceptance passes. Construction-time side effects are also prohibited.

CEGIS: optional explicit refinement configuration supplies the differential budget and maximum rounds. Only corpus-matching candidates are refined. Replay mismatches, retain them with provenance, invalidate all population fitness, and continue evolution without changing the PRNG state. Generation and refinement budgets are independent. Checkpoints embed the authoritative corpus/provenance and state in one atomic envelope; separate corpus/provenance files are projections recoverable after a crash. Resume checks all identities and fitness. No counterexample is discarded or silently reclassified as a target label.

References: https://github.com/containers/bubblewrap and https://man7.org/linux/man-pages/man2/seccomp.2.html . Outstanding deployment prerequisite: kernel namespace/seccomp support; failures abort rather than weaken isolation.

The first affine discovery trial exhausted 1,000 generations after retaining counterexamples: mutation-only search became trapped by the required lexicographic case-match ordering. Add opt-in `search.enumeration_depth` (1–4) and `search.enumeration_proposals` (slots per generation); defaults are both zero, preserving the measured M2 baseline. Proposals deterministically enumerate accumulator chains rooted in a return-typed parameter, with configured unary operators or binary operators and configured parameter/constant operands in either order. No composed seed is inserted and no fixture implementation is consulted. The cursor is checkpointed. This is a complete enumeration only of that bounded chain grammar, not a completeness claim for synthesis. The D1 affine configuration explicitly selects depth 3 and 128 proposals while retaining the 256/1,000 population/generation caps.
