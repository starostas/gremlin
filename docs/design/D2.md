# D2: structured CFG frontend and search

Dependencies: reuse core's typed SSA CFG, validator, interpreter, and pinned RNG; no new dependency. Structured source gains `let mut`, assignment, `if/else`, `while`, `loop`, `break`, and `continue`. Expressions keep explicit operator syntax and exact types. Blocks have lexical scopes; outer mutable variables flow through typed block parameters. Every control-flow edge binds all carried variables simultaneously. Break/continue target the nearest loop; no labels. Unreachable statements are rejected. Infinite loops are valid and bounded by interpreter execution budgets.

Canonical CFG source syntax (`block bN(params) { ... jump/branch/return ... }`) is added for exact source/IR round trips, including irreducible CFGs that cannot be directly reconstructed as structured source. It uses the same validated semantics, rather than introducing a program-counter simulation that would alter step costs.

Search supports explicitly configured bounded CFG mutations, keeping straight-line defaults and M2 reproducibility. Branch insertion divides a selected return into a conditional with two typed result alternatives. Loop insertion carries typed state and uses explicit bounded counters; mutation may also produce nontermination, which remains a timeout failure. Structural candidates are validated before evaluation; no silent repair by the validator. Tests measure validity, timeout handling, and convergence on branch/loop fixtures.

Calls and recursion use a module-level function table, explicit argument/return frames, and a separate maximum call-depth limit.

Call semantics decision: a module names its entry and defines a map of functions. Calls use typed integer signatures and are eager, with argument expressions lowered left-to-right. A call instruction costs one step; each callee return costs one step; argument/frame setup is free. A single shared step budget covers the entire call tree. The entry frame has depth 1; attempting a call when the configured depth is already reached consumes the call step and yields `Timeout(call depth budget exhausted)`. A zero depth immediately times out after validation. Depth is bounded to 1,024 supported frames. Frames are explicit heap data, never host recursive interpreter calls. Source `run` defaults to 64 frames and accepts `--max-call-depth`. Module entry is `main` when present, otherwise the first declared function. Unknown callees and signature mismatches are invalid before execution. Source printing uses canonical CFG bodies when required and preserves module call targets. Internal calls are interpreted; native/GPU/formal backends may explicitly reject calls until their own parity gates cover them.
