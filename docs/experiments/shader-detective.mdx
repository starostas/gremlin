A small color transform is easy to apply but not necessarily easy to infer from input/output pairs. This experiment gives the search packed colors, a compact operator set, and a few constants, then withholds their arrangement.

The three images show the observation, hidden target, and candidate output. Replay follows a measured run; a live GPU run uses the same bounded search.
